## Overview

Global Design Skill is a universal design-system guideline for AI-assisted frontend work.
It is meant for teams that want stricter, less generic output from AI coding agents without losing implementation clarity.

## Design Intent

- Reduce generic layouts and copy
- Force explicit UX decisions before styling
- Keep accessibility and responsive behavior visible
- Make developer handoff concrete instead of interpretive

## Style Foundations

- Visual direction: structured, product-focused, editorial-tech
- Density: calm, readable, and task-oriented
- Hierarchy: strong headline and section hierarchy
- Color: semantic token-driven, OKLCH preferred
- Motion: purposeful only

## Why It Exists

AI-generated interfaces often ship with the same problems:

- vague hero sections
- weak CTA hierarchy
- missing states
- poor mobile behavior
- inaccessible forms
- incomplete implementation notes

This skill exists to turn those outputs into structured, buildable guidance.

## Maintenance Notes

- Keep all recommendations concrete and testable
- Prefer reusable patterns over one-off exceptions
- Update state coverage when new component families are added
- Keep the tone concise and implementation-focused

## Recommended Use

- landing pages
- SaaS apps
- admin panels
- dashboards
- forms
- pricing pages
- frontend handoff specs
- design audits
